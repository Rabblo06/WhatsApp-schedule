# Dashboard

The dashboard is a professional owner/admin interface built with Next.js App Router, React, TypeScript, Tailwind CSS, Lucide icons, and source-owned UI primitives.

Planned routes:

- `/dashboard`
- `/whatsapp`
- `/live`
- `/conversations`
- `/schedules`
- `/reminders`
- `/memory`
- `/users`
- `/groups`
- `/ai`
- `/logs`
- `/health`
- `/settings`

Phase 2 adds `/whatsapp`, showing configuration status, business account, business number, phone number ID, webhook status, last-message placeholders, provider capabilities, and a `wa.me` chat QR when the business phone number is configured. It must not expose access tokens or secrets.
